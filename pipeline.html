12 Compliance Agents
Each agent inspects the normalized Claim model and returns a Finding (PASS / WARN / FAIL). Any FAIL → disposition REVIEW.
Gate rule: CLEAN requires zero FAIL findings across all 12 agents. One or more FAILs → REVIEW — human coder must resolve before submission.
